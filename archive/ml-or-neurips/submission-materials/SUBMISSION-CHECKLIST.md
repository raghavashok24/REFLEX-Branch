## Before you submit (4 items)

1. **Anonymity is the build's default.** This build uses
   `dblblindworkshop`: the author block renders as Anonymous Author(s),
   the abstract points to supplementary material instead of a URL, and
   prior work (REFLEX, arXiv:2608.16155) is cited in third person.
   NOTE: the CFP as verified on 25 Aug 2026 said the workshop is
   single-blind and non-anonymous (`sglblindworkshop`); if that stands,
   swap the option in `main.tex`'s preamble and restore the author
   block with names, emails, and affiliations at submission time.
2. **Upload the supplementary zip** (this folder minus `paper/`) as the
   anonymized repository the abstract promises; if a public repo is
   allowed instead, scrub author metadata before pushing.
   `.gitignore` already excludes `__pycache__/`.
3. **Journal pathway indication**: you may indicate at most one of
   Stochastic Systems / Mathematics of OR / Operations Research.
   Recommendation from the venue analysis: **Stochastic Systems** (APS's own
   journal; highest-probability fit for stability-of-stochastic-feedback +
   applied probability). MOR becomes the right home only if OPEN-1's sharp
   constant is proved before the journal submission.
4. **Compile check on Overleaf** (or locally): `pdflatex → bibtex →
   pdflatex ×2`. Confirm References still start on page 5.
